# Aritificial Intelligence in Computer Graphics

## Image Modification

Models for image modification tasks were trained and evaluated on the [DIV2K](https://www.kaggle.com/datasets/soumikrakshit/div2k-high-resolution-images/data) dataset.

## Tone Mapping

Models for tone mapping were implemented based on the [Learning a self-supervised tone mapping operator via feature contrast masking loss](https://arxiv.org/abs/2110.09866) paper on the [sihdr](https://www.repository.cam.ac.uk/items/c02ccdde-db20-4acd-8941-7816ef6b7dc7) dataset.

## Image Generation

Models for image generation were trained on the [MedMNIST](https://medmnist.com/) dataset.

## Neural Rendering

Models for neural rendering were trained based on images created using a custom 3D renderer.

## Animation Interpolation

Models for animation frame interpolation were trained on [AnimeInterp](AnimeInterp) dataset.
